# 🎸 BAND MANAGER – BATTLE BANDS

## 📋 Descripción
Videojuego RPG de batallas musicales por turnos desarrollado en Godot 4.
El jugador administra una banda de rock desde el garage hasta convertirse
en leyenda derrotando a la banda PANTERA.

## 🎮 Géneros
- RPG (Role Playing Game)
- Estrategia por turnos
- Administrador de recursos
- Progresión por niveles

## 👥 Equipo
- Ruth Rodríguez
- Daniel De la Cruz

## 🛠️ Tecnologías
- Motor: Godot 4.x
- Lenguaje: GDScript

## 🖥️ Pantallas

### Menú Principal
- **Archivo:** `scenes/ui/MainMenu.tscn`
- **Funciones:**
  - **JUGAR** → Carga `BattleScene.tscn`
  - **CRÉDITOS** → Muestra temporalmente los nombres del equipo
  - **SALIR** → Cierra la aplicación
- **Configuración:** Establecido como escena principal del proyecto (Project Settings → Run → Main Scene)
